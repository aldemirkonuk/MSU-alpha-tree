# Player profile (M-PROF)

Status: proposed, 2026-10-18. Generated from `config/metrics.yaml` (category `player_profile`); the YAML is the source of truth and holds the full entry (definition, inputs, variants, as-of rule, parameters, sources) for every id below. Overview and id scheme: [README](README.md).

Games, minutes, usage, roles and positions, role clusters, class and eligibility, returning minutes, transfers, honours.

**95 metrics.** Data tier: box 40, pbp 18, tracking_broadcast 13, tracking_pro_only 1, market 1, external_only 22. Computable now: yes 47, after_pbp 18, after_tracking 14, external 16. Verified: true 70, false 25.

Columns: **tier** = data needed (see README); **now?** = when it can be computed; **level** = the grain it is stored at. Formulas use the inputs listed in the YAML; units are metres, seconds, degrees, m/s, points, possessions and percent (0-100) unless the unit says otherwise.
