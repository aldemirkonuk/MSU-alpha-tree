## Notes

- **ESPN Brick Index (M-SHOOT-067)** exists after all: an ESPN NBA stat (in the ESPN core API and hoopR's NBA docs), not published for college. ESPN's printed formula does not reproduce ESPN's own values; a points form, 2 x (league TS - TS)/100 x (FGA + 0.44 FTA)/(MIN/40), matches 12 NBA player-seasons within about 4%. Kept as partial and labelled reverse-engineered; for MSU it is computed from the box with the D-I season TS%.
- **Corrected definitions:** KenPom home-court advantage (home minus road margins in conference games, halved; Texas Tech example reproduces), Torvik quality games (top 50 by T-Rank; 'venue-adjusted' was not in the source and is dropped), Franks defensive attention (half-court frames only, posterior matchup weights, plain counts in the fallback), the Cervone acceleration field (fitted per player, no pooling) and coarsened state (defended = defender within 1.524 m; end-state values 2, 3, 0).
- **Previously wrong downgrades** reversed: the Nylon Calculus P&R turnover formula and PlayerData's lateral acceleration gates are in the cited pages.
- **Project-defined:** timeout classification (each type mapped to a rules-book article) and the coach tournament rates (the source file's F4% and CHAMP% are not observed rates).
