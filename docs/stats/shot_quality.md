# Shot quality (M-SQ)

Status: proposed, 2026-10-18. Generated from `config/metrics.yaml` (category `shot_quality`); the YAML is the source of truth and holds the full entry (definition, inputs, variants, as-of rule, parameters, sources) for every id below. Overview and id scheme: [README](README.md).

Shot location in the attacked-rim frame, shot diet, shot-clock at release, contest geometry, expected points and shot-making over expected.

**59 metrics.** Data tier: box 2, pbp 36, tracking_broadcast 19, tracking_pro_only 1, external_only 1. Computable now: yes 3, after_pbp 35, after_tracking 20, external 1. Verified: true 48, false 11.
