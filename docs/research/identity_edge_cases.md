# Edge-case matrix for a zero-swap identity layer (11 Nov 2026)

How to read it. Rules refer to unique_parameter.md: CREATE (number anchor), MAINTAIN, VETO. Proposal ids (P01...)
refer to proposals.json. Harness options in `code` exist today in config/identity_pack.yaml or
tools/specgen/identity/obsmodel.py; options marked NEW would have to be added.

Re-lock times are model estimates, not measurements. T1 = one agreeing number read; T2 = two independent reads.
With the harness's good-video rate (0.6 sightings per player-second) T1 is about 2 s and T2 about 4-6 s near side,
6 s and 12-20 s on the far side (rate x 0.3). With the rate implied by published hockey legibility (0.16 per second)
T1 is about 6 s and T2 about 13-20 s near side. No basketball rate is published; measuring it is proposal P28.

Gates common to every row: locked swap events = 0 offline; ID-INV-1 to 5 hold; every demotion and re-lock is logged.
The Gate column lists what is specific to the row.

## Rows the current harness cannot represent

E02, E05, E07, E08, E09, E15, E18 (bursts), E25 and the orientation part of E23 need new simulator options. E04, E06
and E19 are represented only through their effect (a cut, a class error). None of the rows can be closed on the
harness alone: each gate has to be re-run on the labelled gold sample.
